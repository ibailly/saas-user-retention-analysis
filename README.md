# SaaS User Retention Analysis
Analysis of user behavior in a SaaS product focusing on retention, churn, and engagement patterns over time.

## Business Context
A SaaS company operates on a subscription-based model and needs to understand how users interact with the product over time, especially regarding retention and churn behavior.

## Objective
Analyze user behavior data to understand retention patterns, churn rate, and engagement over time.
